## EIP2535

_Implements the base logic for handling function calls in a diamond contract as defined by the
EIP-2535 Diamond Standard. This abstract contract provides a fallback mechanism to forward calls
to the appropriate facet and handles cases where no function is found. It inherits internal
utility functions from `EIP2535Internal`._

### FunctionNotFound

```solidity
error FunctionNotFound(bytes4 _functionSelector)
```

_Error thrown when a function selector does not map to any facet._

#### Parameters

| Name               | Type   | Description                                                                   |
| ------------------ | ------ | ----------------------------------------------------------------------------- |
| \_functionSelector | bytes4 | The function selector that was called and could not be resolved to any facet. |

### receive

```solidity
receive() external payable
```

Allows the contract to accept native currency (e.g., Ether) payments.

_This function is executed when the contract receives plain Ether with no data.
It does not perform any operations besides receiving Ether._

### fallback

```solidity
fallback() external payable
```

Forwards function calls to the appropriate facet based on the function selector.

_If a function selector cannot be resolved to a facet, the `FunctionNotFound` error is thrown. This
fallback function uses inline assembly to: - Retrieve the function selector from the calldata. - Identify the facet address associated with the function selector via `_facetAddress`. - Execute the resolved function using `delegatecall`. - Return any return data or error back to the caller.
This function is executed when no other function matches the function signature of the call.
**Note**: `solhint-disable-next-line no-complex-fallback` is used to disable Solidity linter warnings
for complex fallback logic._

## EIP2535AccessControl

_Extends the `EIP2535` abstract contract to provide access control functionality. This contract utilizes
RBAC (Role-Based Access Control) during initialization and supports the configuration of facets in a
diamond contract._

### DiamondArgs

_Struct to hold arguments required during the diamond contract's constructor. This helps to avoid
"stack too deep" errors by bundling multiple parameters together._

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |

```solidity
struct DiamondArgs {
  struct IAccessControl.Rbac[] rbacs;
  address init;
  bytes initCalldata;
}
```

### constructor

```solidity
constructor(address[] _facets, struct EIP2535AccessControl.DiamondArgs _args) public payable
```

Initializes a new diamond contract instance with facets and access control configurations.

_This constructor is invoked during the deployment of the diamond contract. It performs two main tasks: - Calls `_initializeRbac` to set up role-based access control using the `rbacs` parameter. - Calls `_configureFacets` to set up the diamond's facets and optionally execute an initialization
function._

#### Parameters

| Name     | Type                                    | Description                                                               |
| -------- | --------------------------------------- | ------------------------------------------------------------------------- |
| \_facets | address[]                               | An array of addresses representing the facets to be added to the diamond. |
| \_args   | struct EIP2535AccessControl.DiamondArgs | Struct containing diamond initialization arguments (`DiamondArgs`).       |

### \_diamondCut

```solidity
function _diamondCut(struct IDiamond.FacetCut[] _facetCuts, address _init, bytes _calldata) internal
```

Modifies the diamond by applying the given facet cuts.

_This is the internal version of the `diamondCut` function. It processes the addition, replacement, or
removal of function selectors associated with facets, as specified in the `_facetCuts` parameter. Once
changes are applied, the optional initialization function specified by `_init` and `_calldata` is executed._

#### Parameters

| Name        | Type                       | Description                                                                     |
| ----------- | -------------------------- | ------------------------------------------------------------------------------- |
| \_facetCuts | struct IDiamond.FacetCut[] | The set of changes to apply to the diamond (add, replace, or remove selectors). |
| \_init      | address                    | The address of the initialization contract.                                     |
| \_calldata  | bytes                      | The calldata to execute during initialization.                                  |

### \_facetUpdates

```solidity
function _facetUpdates(address[] _newFacetAddresses, address _init, bytes _calldata) internal
```

Reconfigures the diamond by removing all existing selectors and setting up new facets.

_Removes all selectors from the diamond and applies configuration for the given `_newFacetAddresses`.
Executes an optional initialization function specified by `_init` and `_calldata`._

#### Parameters

| Name                | Type      | Description                                                  |
| ------------------- | --------- | ------------------------------------------------------------ |
| \_newFacetAddresses | address[] | The new set of facet addresses to configure for the diamond. |
| \_init              | address   | The address of the initialization contract.                  |
| \_calldata          | bytes     | The calldata to execute during initialization.               |

## EIP2535Ownable

_Extends the functionality of the EIP-2535 Diamond Standard by incorporating ownership management.
Inherits from `EIP2535` and `OwnableInternal` to provide ownership control and diamond behavior.
This contract simplifies ownership transfer and facet configuration during initialization._

### DiamondArgs

_Struct to bundle arguments used during the diamond constructor.
This approach helps to prevent "stack too deep" errors by consolidating parameters._

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |

```solidity
struct DiamondArgs {
    address owned;
    address init;
    bytes initCalldata;
}
```

### constructor

```solidity
constructor(struct IDiamond.FacetCut[] _facetCuts, struct EIP2535Ownable.DiamondArgs _args) public payable
```

Deploys the diamond contract, sets its ownership, and configures its facets.

_Initializes diamond ownership with the provided `owned` address and applies the facet cuts in `_facetCuts`.
Executes optional initialization logic with `init` and `initCalldata`.
Additional logic can be added after `_diamondCut` for extra setup or to initialize state variables._

#### Parameters

| Name        | Type                              | Description                                                                |
| ----------- | --------------------------------- | -------------------------------------------------------------------------- |
| \_facetCuts | struct IDiamond.FacetCut[]        | Array of `FacetCut` structs to add, replace, or remove function selectors. |
| \_args      | struct EIP2535Ownable.DiamondArgs | Struct with ownership and initialization data for the diamond.             |
