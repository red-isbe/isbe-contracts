## ERC203643InternalCommon

Aggregates the internal functions of ERC20 and ERC3643 standards.

_Provides unified token transfer logic for both ERC20 and ERC3643 standards, including compliance, freeze, cap, and snapshot features._

### \_beforeTokenTransfer

```solidity
function _beforeTokenTransfer(address _from, address _to, uint256 _amount) internal virtual
```

_Internal hook called before any token transfer, mint, or burn.
Handles mint, burn, and transfer operations with validations and snapshot updates._

#### Parameters

| Name     | Type    | Description                                                                |
| -------- | ------- | -------------------------------------------------------------------------- |
| \_from   | address | The address from which tokens are being transferred (address(0) for mint). |
| \_to     | address | The address to which tokens are being transferred (address(0) for burn).   |
| \_amount | uint256 | The amount of tokens being transferred.                                    |

### \_handleMintOperation

```solidity
function _handleMintOperation(address _from, address _to, uint256 _amount) internal
```

_Handles mint operations, including snapshot updates and compliance checks._

#### Parameters

| Name     | Type    | Description                                                                                                                                        |
| -------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| \_from   | address | The address initiating the mint (always address(0)).                                                                                               |
| \_to     | address | The address receiving the minted tokens.                                                                                                           |
| \_amount | uint256 | The amount of tokens being minted. In ERC-3643 mode, compliance hooks may restrict minting. In ERC-20 mode, these hooks are inert and always pass. |

### \_handleBurnOperation

```solidity
function _handleBurnOperation(address _from, uint256 _amount) internal
```

_Handles burn operations, including snapshot updates, freeze management, and compliance hooks._

#### Parameters

| Name     | Type    | Description                                                                                                                                                                           |
| -------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| \_from   | address | The address from which tokens are being burned.                                                                                                                                       |
| \_amount | uint256 | The amount of tokens being burned. In ERC-3643 mode, auto-unfreeze may be triggered and compliance hooks may restrict burning. In ERC-20 mode, these hooks are inert and always pass. |

### \_handleTransferOperation

```solidity
function _handleTransferOperation(address _from, address _to, uint256 _amount) internal
```

_Handles transfer operations, including snapshot updates, compliance, and freeze checks._

#### Parameters

| Name     | Type    | Description                                                                                                                                                          |
| -------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| \_from   | address | The address from which tokens are being transferred.                                                                                                                 |
| \_to     | address | The address to which tokens are being transferred.                                                                                                                   |
| \_amount | uint256 | The amount of tokens being transferred. In ERC-3643 mode, compliance and freeze hooks may restrict transfers. In ERC-20 mode, these hooks are inert and always pass. |

### \_unfreezeIf3643Mode

```solidity
function _unfreezeIf3643Mode(address _from, uint256 _amount) internal
```

_Unfreezes tokens if operating in ERC-3643 mode and insufficient free balance._

#### Parameters

| Name     | Type    | Description                                                    |
| -------- | ------- | -------------------------------------------------------------- |
| \_from   | address | The address from which tokens are being transferred or burned. |
| \_amount | uint256 | The amount of tokens being transferred or burned.              |

### \_calculateFreeBalance

```solidity
function _calculateFreeBalance(address _account) internal view returns (uint256)
```

_Calculates the free balance of an account (total balance minus frozen tokens)._

#### Parameters

| Name      | Type    | Description                 |
| --------- | ------- | --------------------------- |
| \_account | address | The address of the account. |

#### Return Values

| Name | Type    | Description                      |
| ---- | ------- | -------------------------------- |
| [0]  | uint256 | The free balance of the account. |
