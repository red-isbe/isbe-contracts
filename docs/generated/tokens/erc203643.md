## ERC203643InternalCommon

Aggregates the internal functions of ERC20, ERC3643

_Provides unified token transfer logic for both ERC20 and ERC3643 standards_

### \_beforeTokenTransfer

```solidity
function _beforeTokenTransfer(address _from, address _to, uint256 _amount) internal virtual
```

_Hook that is called before any token transfer_

#### Parameters

| Name     | Type    | Description                                           |
| -------- | ------- | ----------------------------------------------------- |
| \_from   | address | Address tokens are transferred from (0x0 for minting) |
| \_to     | address | Address tokens are transferred to (0x0 for burning)   |
| \_amount | uint256 | Amount of tokens to transfer                          |
