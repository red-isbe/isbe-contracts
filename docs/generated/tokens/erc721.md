### approve


## IERC721Isbe

This interface defines the standard functions, events, and errors for an ERC721 token,
extending the standard ERC721 and ERC721Metadata interfaces.

_This interface introduces the `initializeErc721` function and custom errors specific to
this implementation. It serves as a blueprint for implementing contract functionality while
adhering to the ERC721 specification._

### Erc721Initialized
